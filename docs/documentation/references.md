# References & Professional Resources

This bibliography lists standards, specifications, and professional guidance relevant to the documentation methodology. Always consult the current official edition before applying a requirement.

## Standards

- ISO/IEC/IEEE 26514 — Design and development of information for users.
  Official ISO catalogue: https://www.iso.org/
- DITA (Darwin Information Typing Architecture) — OASIS standard for structured, topic-based information.
  OASIS: https://www.oasis-open.org/

## API specifications

- OpenAPI Specification: https://spec.openapis.org/oas/latest.html
- Web Services Description Language (WSDL) 1.1: https://www.w3.org/TR/wsdl
- SOAP 1.2: https://www.w3.org/TR/soap12/
- XML Schema: https://www.w3.org/XML/Schema

## Architecture and modeling

- C4 Model: https://c4model.com/
- Object Management Group — UML specifications: https://www.omg.org/spec/UML/

## Documentation structure and editorial guidance

- Diátaxis: https://diataxis.fr/
- Microsoft Writing Style Guide: https://learn.microsoft.com/style-guide/
- Google Developer Documentation Style Guide: https://developers.google.com/style

## Source documentation formats and workflows

- Markdown Guide: https://www.markdownguide.org/
- AsciiDoc documentation: https://docs.asciidoctor.org/
- Git documentation: https://git-scm.com/doc
- GitHub Actions documentation: https://docs.github.com/actions

## Database vendor documentation

- Oracle Database documentation: https://docs.oracle.com/en/database/

## Reference management

For each project, record the exact specification or standard edition used, access date where useful, applicable scope, and any project-specific interpretation. This list is a professional reference set; it is not a declaration that every item was adopted or used in every project.
